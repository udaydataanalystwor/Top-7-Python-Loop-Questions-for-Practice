# Top 7 Python Loop Questions

A Jupyter notebook with 7 practice problems on Python loops, each with working code and output. I built this while learning Python for data analytics.

## What's inside

| # | Problem | Concepts practiced |
|---|---------|--------------------|
| 1 | Print multiplication tables for a range of numbers | Nested `for` loops, functions, `range()` |
| 2 | Find names that contain the letter "a" more than once | Looping over a list, `str.count()`, conditions |
| 3 | Print name, age and locality from three parallel lists | `range(len())`, indexing |
| 4 | Print a string in reverse, one character per line | Reverse `range()`, negative step |
| 5 | Count uppercase letters in a string | `str.isupper()`, counters |
| 6 | Split students into pass and fail lists (marks above 35 pass) | Looping over a dictionary, `append()` |
| 7 | Merge two product inventories and add quantities | `dict.items()`, merging dictionaries |

## Skills demonstrated
- Python fundamentals: loops, conditions, functions
- Working with lists, strings and dictionaries
- Writing readable code with clear logic

## How to run
1. Open `Top_7_Loop_Questions.ipynb` in [Google Colab](https://colab.research.google.com/) or Jupyter Notebook.
2. Run the cells from top to bottom.
